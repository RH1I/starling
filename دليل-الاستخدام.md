# 🎮 Starling — Minecraft: Java Edition 26.3, rewritten in Rust

A native Rust client for Minecraft: Java Edition 26.3 (fan project, MIT —
upstream: Horizon by Ludovic Marie and contributors). This fork adds
**turnkey Linux setup tooling** and a **documented Windows 11 cross-build**.

---

## ▶️ Run on Linux (from source)

```bash
# 1. Build (once)
cargo build --release -p horizon-client

# 2. Prepare game resources from your own Minecraft: Java Edition 26.3 copy
#    (see the upstream prepare flow in PLAY.txt — Horizon ships none of
#     Mojang's code, textures or sounds)

# 3. Launch from the repo root — the client reads
#    .local/horizon-client/26.3 relative to the working directory
./starling.sh
```

`starling.sh` (portable, path-independent):
- backs up your worlds before **every** launch (`~/starling-backups`, last 8) + one snapshot per day (last 14)
- refuses to open a second instance (raises the existing window instead)
- captures each launch's stdout/stderr to `.local/starling-launch-logs/` (last 5)
- sets `PIPEWIRE_LATENCY=256/48000` to avoid ALSA crackling on PipeWire systems

`starling-restore.sh` restores any backup interactively (keeps a pre-restore copy first).

## ▶️ Run on Windows 11

See **[BUILD-WINDOWS.md](BUILD-WINDOWS.md)** — cross-compile from Linux with
cargo-xwin + Clang 19, CRT statically linked (no VC++ Redistributable needed),
then package the exe with prepared resources and a `starling.bat` launcher.

## 🛠️ Development

Standard cargo workspace (42 crates, Rust 1.85+, edition 2024):

```bash
cargo build --release -p horizon-client   # the game
cargo test -p horizon-world               # tests per crate
./target/release/horizon-ctl --help       # server control tools
```

See [AGENTS.md](AGENTS.md) for the codebase map and [ROADMAP.md](ROADMAP.md)
for upstream plans.

## 📁 Data layout

| Path | What |
|---|---|
| `.local/horizon-client/26.3/` | prepared resources (generated by `horizon-prepare`) |
| `.official-files/` | Mojang's official downloads (gitignored — never publish) |
| `saves/` | worlds |
| `~/starling-backups/` | automatic world backups |
